# อ่านเข้าใจมั้ย

> *Do you understand what you read?* เว็บฝึกอ่านและจับใจความ ที่ให้ผู้ใช้แข่งกันสะสมคะแนนตลอดทั้งปี

**สถานะ:** ช่วงกำหนด concept (ยังไม่มีโค้ด)

## โปรเจกต์นี้คืออะไร

เว็บที่มีบทความหลายหมวดให้ผู้ใช้อ่าน แล้วเขียนสรุปใจความสำคัญส่งเข้าระบบ ระบบให้คะแนนแยกตามเกณฑ์ย่อย สะสมคะแนนและจำนวนบทความที่อ่านตลอดปี และมอบรางวัลประจำปีให้ผู้ที่ทำได้ดีที่สุด

โปรเจกต์นี้เป็นงานชิ้นแรกในชุด portfolio มีเป้าหมายคู่กัน คือ **เป็นเว็บที่ใช้งานได้จริง** และ **เป็นสนามฝึกทักษะนักพัฒนา fullstack** (ดูหัวข้อเป้าหมายการเรียนรู้)

## วิธีเล่น

1. เลือกบทความจากหมวดที่สนใจ
2. อ่านแล้วเขียนสรุปใจความสำคัญ
3. ระบบให้คะแนนแยกเป็นหลายเกณฑ์ บทความที่ยากกว่าได้คะแนนต่างจากบทความทั่วไป
4. คะแนนและจำนวนบทความที่อ่านสะสมไปตลอดปี สิ้นปีประกาศผู้ชนะ

## ฟีเจอร์

### บทความและการสรุป
- หมวดหมู่บทความ
- ระดับความยากของบทความ (เรื่องทั่วไป เรื่องเฉพาะทาง เช่น อวกาศ) ซึ่งให้คะแนนไม่เท่ากัน
- บันทึกร่างคำตอบไว้ก่อนส่ง
- โหมดสแกนเอกสาร สำหรับผู้ใช้ที่เขียนสรุปลงกระดาษ

### ระบบคะแนน
คะแนนของแต่ละบทความแยกเป็นเกณฑ์ย่อย

| เกณฑ์ | ความหมาย | สถานะ |
|---|---|---|
| คำศัพท์เฉพาะ | ใช้คำสำคัญของบทความได้ถูกต้องและครบ | ตัดสินใจแล้ว |
| การเว้นวรรค | ไม่เว้นวรรคตัดกลางคำที่รวมกันแล้วมีความหมายเดียวในบริบท เช่น "อาหารไทย" ต้องไม่เขียนเป็น "อาหาร ไทยจังเลย" | ตัดสินใจแล้ว |
| ครอบคลุมใจความสำคัญ | สรุปได้ครบประเด็นหลัก | ยังไม่ตัดสินใจ |
| ความกระชับ | ไม่ยาวเกินจำเป็น | ยังไม่ตัดสินใจ |
| ความถูกต้อง | ไม่เพิ่มข้อมูลที่ไม่มีในบทความ | ยังไม่ตัดสินใจ |
| ใช้คำของตัวเอง | ไม่ลอกประโยคเดิมจากบทความ | ยังไม่ตัดสินใจ |
| ตัวสะกดและไวยากรณ์ | เขียนถูกต้อง | ยังไม่ตัดสินใจ |

### อันดับและรางวัลประจำปี
- หน้าผู้นำอันดับล่าสุดของปีปัจจุบัน
- หน้าแชมป์เก่าของแต่ละปี
- หน้ารางวัล โดยรางวัลที่กำหนดไว้แล้ว ได้แก่ **คะแนนรวมสูงสุด** และ **อ่านบทความมากที่สุด** (เพิ่มประเภทอื่นได้ภายหลัง)

### ผู้ใช้งาน
- เข้าสู่ระบบด้วย Gmail
- โปรไฟล์ที่เก็บประวัติการสรุป คะแนนแยกเกณฑ์ และรางวัลที่เคยได้

## นอกขอบเขต (ตัดออกแล้ว)

- เข้าสู่ระบบด้วยเบอร์โทร
- ระบบตรวจจับว่าใช้ AI ช่วยเขียนคำตอบ
- รางวัลรายเดือน (เปลี่ยนเป็นรายปี)

## ประเด็นที่ยังต้องตัดสินใจ

- ที่มาของบทความ (ไอเดียเดิมคือให้ AI สร้าง) และวิธีกำหนดระดับความยาก
- วิธีให้คะแนนแต่ละเกณฑ์ว่าตรวจด้วยโค้ด ด้วย AI หรือผสมกัน
- เกณฑ์ย่อยที่ยังไม่ตัดสินใจจะใช้ตัวไหนบ้าง และน้ำหนักคะแนน
- รางวัลที่จะมอบเป็นรูปแบบใด
- Tech stack, framework และที่ deploy (ต้องใช้บริการฟรีเป็นหลัก)
- แผนการพัฒนาเป็นเฟส

## เป้าหมายการเรียนรู้

โปรเจกต์นี้ใช้ฝึกทักษะต่อไปนี้ และจะบันทึกเหตุผลการตัดสินใจไว้ในเอกสารของโปรเจกต์

1. เลือกใช้ tool แต่ละตัวให้เหมาะกับงาน
2. เลือก framework
3. จัดการ performance ของโค้ด
4. ทำงานแบบ fullstack developer
5. deploy ขึ้น cloud
6. สั่งงานและทำงานร่วมกับ AI อย่างมีประสิทธิภาพ
7. ออกแบบโครงสร้างโปรเจกต์
8. เข้าใจการทำงานก่อนหลังพร้อมกัน (concurrency)
9. เข้าใจการรับส่งข้อมูล
10. เขียน prompt สั่งงาน AI ให้ได้ผลดีที่สุด
